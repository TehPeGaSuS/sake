sake Documentation

sake is a personal IRC bouncer, forked from soju. See the repository and the wiki for a full walkthrough (quickstart, web admin panel, differences from soju).

  • sake(1) — the bouncer daemon: command-line flags, config file, and the BouncerServ IRC service (network/channel/certfp/sasl/user management)
  • sakectl(1) — remote-control tool for a running sake instance
